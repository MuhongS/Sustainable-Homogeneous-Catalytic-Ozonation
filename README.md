# Research Code for Copper-Containing Wastewater Treatment
## Overview
This repository contains the source code and computational scripts associated with the research manuscript entitled "Sustainable Approach to Homogenous Catalytic Ozonation: Degradation of Recalcitrant Azole Species with Waste Copper Ions".

The code is provided to support transparency, reproducibility, and further research.

## Repository Contents

scripts -  Scripts used for data processing, modeling, and analysis.

data.csv - Example datasets.

README.md — Documentation for the repository.

## Software Requirements
The codes were developed and tested using the following software:

Programming Language: R

Software Version: 4.4.2

Operating System: Windows

Required Packages: "caret", "glmnet", "rapart", "nnet"
